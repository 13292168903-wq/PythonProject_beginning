# NumPy 学习练习

记录我学习 NumPy 基础时写的 21 个练习脚本，代码放在 `numpy_beginning/`，为后续学习 PyTorch 打基础。

## 学过的内容

- 数组创建：`array`、`arange`、`zeros`、`ones` 和随机数生成。
- 数组属性：`shape`、维度、`dtype` 和类型转换。
- 数组访问：索引、花式索引、一维与二维切片。
- 数据共享：变量绑定、切片视图和 `copy` 副本。
- 形状操作：转置、翻转、`reshape`、拼接和分裂。
- 数组运算：广播、逐元素运算、`np.dot` 向量与矩阵乘法。
- 数学与统计：绝对值、三角函数、对数、指数、最大最小值、求和、均值和标准差。
- 条件筛选：布尔数组、`any`、`all`、掩码和 `np.where`。
